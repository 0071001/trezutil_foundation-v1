## Usage

1. Lire `PRODUCT_SPECIFICATION.md` pour la vision produit.
2. Lire `DOMAIN_MODEL.md` pour le modèle de domaine global.
3. Lire les modèles spécialisés (`LISTING_MODEL.md`, `CATEGORY_MODEL.md`, etc.).
4. Lire `API_CONTRACT.md` et `EVENT_CONTRACT.md` pour les contrats.
5. Lire `SECURITY_MODEL.md` pour les règles d’isolation et d’autorisation.
6. Lire `TEST_STRATEGY.md` pour la stratégie de tests.
7. Lire les ADRs pour les décisions d’architecture.
