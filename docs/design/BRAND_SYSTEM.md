# Trezutil Brand System

## Visual Identity

Trezutil's visual identity communicates:

```
Premium. Fluid. Human. Modern. Commerce-first.
```

---

## Brand Principles

| Principle | Expression |
|-----------|-----------|
| **Premium** | Refined spacing, high-quality content, intentional typography |
| **Fluid** | Smooth transitions, connected states, progressive reveal |
| **Human** | Conversational language, warm colors, accessible design |
| **Modern** | Clean layouts, minimal decoration, current design language |
| **Commerce-first** | Every surface serves commerce: discover, search, view, act |

---

## Brand Tokens

### Primary Colors

| Token | Value | Usage |
|-------|-------|-------|
| `trezutil-blue` | `#155EEF` | Brand, primary actions, links, interaction |
| `deep-navy` | `#0B1220` | Strong surfaces, navigation, dark mode |
| `ice` | `#F5F8FC` | Backgrounds, card surfaces |
| `mint` | `#35D0BA` | Available, confirmed, success, active |
| `coral` | `#FF7A66` | Urgent, attention (sparingly) |
| `white` | `#FFFFFF` | Cards, modals, clean surfaces |

### Dark Palette

| Token | Value | Usage |
|-------|-------|-------|
| `dark-surface-1` | `#080D17` | Dark mode background |
| `dark-surface-2` | `#101827` | Cards, panels |
| `dark-surface-3` | `#172238` | Inputs, elevated elements |

### Color Usage Rules

- **Mint** communicates: available, confirmed, success, active
- **Blue** communicates: brand, primary action, links, interaction
- **Coral** used sparingly for: urgent, attention, error emphasis
- **Deep Navy** communicates: strong surfaces, navigation, dark mode

## Typography

### Font Stack

```css
/* Primary UI / Headings */
font-family: 'Manrope', 'Plus Jakarta Sans', sans-serif;

/* Body / UI fallback */
font-family: 'Inter', system-ui, sans-serif;
```

### Type Scale

| Level | Size | Weight | Usage |
|-------|------|--------|-------|
| Display | 48px | 800 | Hero titles |
| H1 | 32px | 700 | Page titles |
| H2 | 24px | 700 | Section headings |
| H3 | 20px | 600 | Card titles |
| Body | 16px | 400 | Default text |
| Small | 14px | 400 | Secondary text |
| Caption | 12px | 500 | Labels, metadata |
