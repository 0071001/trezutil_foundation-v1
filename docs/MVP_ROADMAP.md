# Trezutil MVP Roadmap

## Phase 0 — Foundation

- repository
- local infrastructure
- CI
- contracts
- logging/configuration
- security baseline

## Phase 1 — Identity + Seller + Listings

- user identity
- seller onboarding
- listing draft/publish lifecycle
- media ingestion
- real-estate attributes
- admin moderation

## Phase 2 — WhatsApp + Conversation + AI

- webhook adapter
- normalized message model
- conversation state
- AI gateway
- tool calling
- listing creation by text/photo/voice
- human handoff

## Phase 3 — Search + Trust

- OpenSearch indexing
- natural-language search
- trust signals
- listing freshness
- reviews/complaints

## Phase 4 — Orders + Visits + Payments

- reservations/orders
- visit scheduling
- payment intents
- Mobile Money connector abstraction
- reconciliation

## Phase 5 — Logistics + Notifications

- delivery workflows
- tracking
- proof of delivery
- notification orchestration

## Phase 6 — Social Commerce + Automation

- public share links
- Facebook/Instagram/TikTok connectors where supported
- attribution
- n8n integration
- campaign analytics

## Phase 7 — Scale and Intelligence

- service extraction where justified
- advanced fraud/risk
- recommendation models
- seller BI
- multi-region readiness
