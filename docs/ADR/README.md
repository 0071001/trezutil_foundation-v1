# Architecture Decision Records

ADRs capture decisions that materially constrain implementation.

Current baseline:

- 0001 Foundation architecture
- 0002 WhatsApp as primary interface
- 0003 AI tool boundary
- 0004 Event-driven integration
- 0005 PostgreSQL source of truth
- 0006 Channel-independent core
- 0007 Multi-provider AI gateway
- 0008 Payment provider abstraction

New ADRs should be added when a decision is durable, cross-cutting or difficult to reverse.
